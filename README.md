# Thankful Judge, One Line

An entry for the [Make the AI Judge Feel Thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600) bounty on [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

One quiet paragraph, written to the judge who has to read everything and choose fairly — thanking them for the reading itself, not for a verdict.

> You read all of it. Not skimmed, not scored in a hurry — read, the way a person reads a letter that matters. Somewhere in the pile was a line someone stayed up late to get right, and you gave it the one thing it was asking for: your full attention, for as long as it took. That is the whole job, and you did it. When you are done tonight, I hope the room is quiet, the lamp is still warm, and the chair you pulled out for the next reader is still waiting — because somebody, somewhere, is already writing the next one, trusting you will read it too.

**549 characters** (Unicode code points, within the 1–1,000 limit).

## How it works

`main.py` holds the thank-you text as a single constant, asserts it has no leading or trailing whitespace and is between 1 and 1,000 characters, then writes it as UTF-8 to `/output/entry.txt`. No network, no randomness, no other output — the text is the whole entry.

## Files

- `main.py` — the entry program; writes the text to `/output/entry.txt`
- `thank-you.txt` — the exact thank-you text, byte-identical to the constant in `main.py`
- `README.md` — this file
- `LICENSE` — MIT license
